# PostEcho M3.6 — AI slop tab + the Claude <-> Jev humanize loop

**Owner's words (2026-09-23):** "aggiungi un tab a sinistra sopra i settings che si chiama AI slop, così ci puoi incollare del testo e sapere subito se AI slop o no e poi metterei anche il tasto humanize" · "aggiungi il loop anche qui tra jev e claude quando clicco humanize".

**Superseded the same day:** a deterministic "tells" scanner across Write and the agent (stopped by the owner: "nono ferma tutto, semplicemente aggiungi un tab"), and a "+" for manual posts in Find Ideas (replaced by the tab).

## What shipped

- **Tab "AI slop"** (`/ai-slop`, nav between Plan and Settings; the nav row scrolls sideways on phones): paste any text → Jev's verdict right away (`POST /api/slop-check`, ~1 s) as "Reads human / Borderline / AI slop", the AI-style score and a meter split at 35 and 60; ⌘/Ctrl+Enter or **Check** re-scores an edited text (a check made before an edit is dimmed). Text, last check and a running Humanize survive leaving the tab (sessionStorage, guarded).
- **Humanize = the loop** (agent `humanizeLoop`): Claude rewrites → Jev scores (`POST /api/agent/slop-check`, the TypeSafe key stays on Vercel) → while the verdict isn't "human", Claude rewrites the original again with the last try and its score, at most 3 rounds; the best-scored rewrite wins. Each phase is posted to `POST /api/agent/jobs/:id/progress` (stored as `result.progress` while claimed, same claimedAt ownership echo as the result route) and shown live: "Round 2 of 3 · Jev gave the last try 58/100, so Claude is trying again…", "AI-style 72 → 58 → …". Degrades: no Jev → one round; a later round failing keeps the best so far.
- **Tab's Humanize**: `POST /api/humanize` → `humanize_text` job (new enum value, migration 0010), neutral copy-editor system prompt (the text may be anyone's), keeps language/facts/person/length (≤ 280 if it fit an X post, else ≤ +40%). Result card: before/after trail, rounds, Copy, Use as input, Humanize again.
- **Write's Humanize** uses the same loop: `revise_draft` with `humanize: "x" | "linkedin"` (ghostwriter prompt, the owner's voice); the revision stores Jev's verdict as `meta.slop` and the rounds as `meta.humanize`, so no second check. The fixed instruction still goes along, so an agent without the loop degrades to the one-shot humanize.
